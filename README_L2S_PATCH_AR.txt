تعديلات L2S Builder - نسخة فحص ملفات الإعداد

التعديلات:
1) إضافة فحص لملفي settings.gradle وsettings.gradle.kts لاكتشاف ملفات apply-from المكتوبة بمسار نصي واضح لكنها غير موجودة.
2) عرض المشكلة في تقرير «فحص المشروع» قبل بدء Gradle، مع اسم الملف المفقود وطريقة المعالجة.
3) إيقاف البناء مبكرًا إذا كان settings.gradle يشير إلى ملف إعداد مفقود، بدل تنزيل Gradle ثم إظهار خطأ عام.
4) لم يُنشأ أي ملف Gradle بديل فارغ، ولم تُغيّر إصدارات AGP أو SDK أو إعدادات المشروع تلقائيًا بسبب هذا الخطأ.

ملاحظات مهمة:
- هذا الإصلاح يعالج التشخيص المبكر لملفات إعداد settings.gradle المفقودة؛ لا يمكنه استعادة محتوى SharedModules/core_settings.gradle الأصلي إذا لم يكن ضمن المشروع.
- منطق اختيار Gradle الموجود مسبقًا لدعم Java 21 بقي كما هو. بعض المشاريع التي تستخدم AGP قديمًا جدًا قد تحتاج أيضًا إلى إصدار JDK متوافق أو ترقية AGP مدروسة.
- تم التحقق من مطابقة نمط اكتشاف apply-from على المثال SharedModules/core_settings.gradle، لكن لم أتمكن من إجراء بناء APK كامل في هذه البيئة؛ اختبر الملف على L2S Builder قبل اعتماد النسخة نهائيًا.
