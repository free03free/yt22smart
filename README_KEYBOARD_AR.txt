لوحة المفاتيح المدمجة (عربي / إنجليزي / رموز)
=============================================
المشكلة: كيبورد الجهاز يُغلق نافذة البحث عند الخروج منه فيضيع النص المكتوب.
الحل: نافذة بحث بلوحة مفاتيح داخل التطبيق نفسه، لا تفتح كيبورد الجهاز أبداً.

- مفتاح «ع» / «EN»: تبديل اللغة (تُحفظ آخر لغة). مفتاح «؟123»/«ABC»: الرموز والأرقام.
- مفتاح ⇧: في الإنجليزي أحرف كبيرة لمرة واحدة، وفي العربي الحركات (فتحة، ضمة، شدة...) وأ إ آ ؤ ئ وحروف إضافية (پ چ ڤ گ).
- ◀ ▶ لتحريك المؤشر، ⌫ حذف حرف (ضغطة مطوّلة = حذف كلمة)، «مسح» يفرغ الحقل، «✓ موافق» ينفّذ البحث.
- يعمل باللمس والريموت (الأسهم + OK) وكيبورد فعلي (الكتابة مباشرة).
- حفظ النص: بعد كل حرف يُحفظ النص كمسودة. إذا خرجت بزر الرجوع أو إلغاء أو أغلقت التطبيق، يعود نفس النص عند فتح البحث مرة أخرى. لا يُمسح إلا بزر «مسح».
- لا يُغلق بلمس خارج النافذة (لتفادي ضياع النص بالخطأ).

أماكن التطبيق: بحث قسم IPTV في القائمة الجانبية، بحث مدير القنوات (IptvManagerActivity)، بحث منتقي البورتالات.
الملفات: common/.../utils/InAppKeyboardDialog.java (جديد) + تعديلات في IptvSection وIptvManagerActivity وIptvPortalPickerPresenter وstrings (en/ar: inapp_kb_clear).
لاستعمالها في أي حقل آخر: InAppKeyboardDialog.show(context, title, hint, initial, text -> { ...; return true; });

بحث يوتيوب (جديد)
=================
- حقل البحث في بحث يوتيوب صار يفتح نفس الكيبورد المدمج عند الضغط عليه (OK بالريموت أو لمس)، ولا يظهر كيبورد الجهاز.
- عند «✓ موافق» يُنفَّذ البحث. وإن خرجت بزر الرجوع دون بحث، يبقى النص المكتوب داخل حقل البحث ويعود في المرة القادمة.
- إعدادات > البحث > «الكيبورد المدمج (عربي / إنجليزي)»: مفعّل افتراضياً، ويمكن إيقافه للرجوع لكيبورد الجهاز (يسري عند فتح البحث من جديد).
- «إظهار الكيبورد تلقائياً» صار يعني فتح الكيبورد المدمج تلقائياً عند دخول البحث.
الملفات: smarttubetv/.../mod/leanback/search/SearchSupportFragment.java، tags/SearchTagsFragment.java، common/.../prefs/SearchData.java، SearchSettingsPresenter.java، strings (inapp_kb_enable, inapp_kb_search_title).
